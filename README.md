# 팔팔마을 — 방치형 성장 관찰 게임

스타듀밸리 풍 픽셀 아트로 만든 현대 한국 동네 **팔팔마을**. 주민 8명이 각자의 일과대로 살아가며 성장하고, 친해지고, 사건을 일으킵니다. 플레이어는 지켜보기만 하면 됩니다.

## 실행

`game/index.html`을 브라우저로 열면 됩니다(빌드 불필요). 로컬 서버로 열려면:

```bash
python -m http.server 8765
```

→ http://localhost:8765/game/

## 조작

| 입력 | 동작 |
|---|---|
| 드래그 / 휠 | 지도 이동 / 확대·축소 |
| 캐릭터·건물 배지 클릭 | 선택 + 따라가기, 오른쪽 패널에 일과·기록·스킬·관계·일기 |
| Space / 1~4 | 일시정지 / 1·2·4·8배속 |
| ↺ | 처음부터 다시 |

진행은 브라우저에 자동 저장되며, 창을 닫아둔 동안의 시간도 일부 반영됩니다(최대 게임 2일).

## 시스템

- **납치 사건**: 평일 하교 시간에 랜덤 발생. 정의겸이 엉뚱한 곳을 헤매다가 그날 안에 구출·체포 → 심문 → 마음이 여려 석방. 곽현지는 그날 집 밖에 안 나옴.
- **연애**: 성인끼리, 나이·성별 무관. 친밀도 → 썸 → 고백(성공/거절) → 연인 → 데이트, 가끔 다툼·이별.
- **랜덤 이벤트**: 소나기, 광장 길고양이, 플리마켓, 버스킹, 치킨 파티, 몸살로 병원행, 훈련 중 부상, 우연한 만남.
- **성장**: 체력·지능·요리·업무·사교·매력 스킬(Lv.10까지)과 캐릭터별 기록(지각, 납치, 맥주, 야근 …).

## 파일

- `game/` — 게임 (`js/data.js` 주민·일과, `js/sim.js` 시뮬레이션, `js/world.js` 지도·건물 그래픽, `js/render.js`, `js/ui.js`)
- `characters/` — 스프라이트·초상화·페르소나 (`tools/generate_characters.py`로 재생성)
