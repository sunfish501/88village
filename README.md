# 팔팔마을 — 방치형 성장 관찰 게임

스타듀밸리 풍 픽셀 아트로 만든 현대 한국 동네 **팔팔마을**. 주민 8명이 각자의 일과대로 살아가며 성장하고, 친해지고, 사건을 일으킵니다. 플레이어는 지켜보기만 하면 됩니다.

## 실행

`game/index.html`을 브라우저로 열면 됩니다(빌드 불필요). 로컬 서버로 열려면:

```bash
python -m http.server 8765
```

→ http://localhost:8765/game/

## 🤖 NPC 인격 AI (OpenRouter · Claude)

주민 대화를 AI가 성격, 관계, 기억, 마을 소식에 맞게 직접 씁니다. 기본값은 OpenRouter의 DeepSeek V4 Flash이고, Claude도 선택할 수 있습니다. 대화 결과(약속, 추천, 비번 공유, 소문, 플러팅, 호감도, 기억)는 게임에 그대로 반영됩니다.

- **나만 쓰기**: 게임 오른쪽 위 **🤖 AI** → API 키(`sk-or-…` OpenRouter / `sk-ant-…` Claude) 붙여넣기 → "저장 + 연결 테스트". 키는 그 브라우저에만 저장됩니다.
- **로컬 개발**: `game/js/ai-local.example.js`를 `ai-local.js`로 복사해 키를 넣습니다. 이 파일은 git에 올라가지 않습니다.
- **모두에게 켜기**: `server/` 의 Cloudflare Worker를 배포(키는 서버 비밀값)하고 `game/js/ai-config.js`의 `proxyUrl`에 주소를 넣습니다. 자세한 방법은 [server/README.md](server/README.md)를 보세요.
- **기본 설정**:
  - 모델: DeepSeek V4 Flash (OpenRouter, 대화 1회 약 $0.0003)
  - 빈도: 하루 80회
  - 나머지 대화: 규칙 기반 대사로 진행
- **키가 없거나 오류가 나면**: 자동으로 규칙 기반 대화로 돌아갑니다.

### 🤖 AI 감독: 매일 바뀌는 하루
- 매일 오후 4시(게임 시간)에 AI 감독이 **다음 날**을 정합니다:
  - 팔팔일보 1면 헤드라인
  - 그날의 이벤트 0~3개
  - 주민별 메모
- 이어서 주민 8명 각자의 **하루 일과표**를 AI가 새로 짭니다. 기본 일과(직업·등교·출퇴근·고유 습관)는 지키고, 기분·관계·약속·이벤트에 맞춰 매일 다르게 바뀝니다.
- AI가 고른 활동은 그 주민에게 허용된 것만 받아들이고, 실패하면 원래 일과로 돌아갑니다.
- 가끔(최소 4일 간격) 대형 사건이 터집니다:
  - ⛈️ 태풍
  - 🔌 정전
  - 🔥 화재 (건물에 불, 대피·진압, 영업 중단)
  - 🌊 하천 범람
  - 🤒 독감 유행
  - 🛸 UFO
  - ⚔️ **칠칠마을과의 전쟁** (사이렌, 폭발, 방어전, 부상자 병원행, 평화 협정)
- AI가 꺼져 있어도 대형 사건은 낮은 확률로 랜덤 발생합니다.
- **📰 신문** 버튼: 오늘의 헤드라인, 마을 일정, 주민들의 아침 한마디·목표.
- **비용**: 게임 하루에 약 9회 호출, 약 $0.0015. 🤖 AI 설정에서 끌 수 있습니다.

## 시스템

- **팔팔법**: 모든 건물에 비밀번호. 주인이 없으면 비번 아는 사람만 출입 가능. 무단출입 → 반성문, 절도 → 광장 청소 사회봉사, 신고되면 정의겸 출동(가끔 훈방).
- **납치 사건**: 평일 하교 시간에 랜덤 발생, 대상은 주민 누구나(곽현지 확률 최고). 정의겸이 엉뚱한 곳을 헤매다 그날 안에 구출·체포 → 심문 → 마음이 여려 석방. 곽현지는 그날 집 밖에 안 나옴. 정의겸을 납치하려 하면 즉시 체포, 유치장 1일.
- **연애 (마을 절대 규칙)**: 성인끼리, 나이·성별 무관. 연인은 한 명만. 꼬시기는 자유라 연인이 있어도 썸이 생길 수 있고, 들키면 싸움·이별, 다른 사람과 사귀려면 먼저 헤어짐(환승). 헤어지면 집 비번을 바꾸기도 함.
- **기억하는 대화**: 대화 내용을 기억해서 나중에 행동함 — 약속(정한 시간에 실제로 만남, 못 오면 펑크), 장소 추천(나중에 찾아가고 다음에 만나면 후기), 집 비번 공유, 소문 전파(범죄 소문은 호감도 하락).
- **교통**: 큰 사거리에 신호등이 있고, 차들은 신호와 앞차 간격을 지킵니다. 아주 가끔(최소 2일 간격) 딴짓하던 차가 길을 건너던 주민을 칩니다. 그러면 이렇게 처리됩니다:
  1. 운전자가 내려 119·112에 신고합니다.
  2. 🚑 구급차가 쓰러진 주민을 팔팔팔병원으로 옮깁니다.
  3. 🚓 경찰차(정의겸이 비어 있으면 직접 운전)가 운전자를 연행합니다. 운전자는 면허 정지 처분을 받고 범죄 기록에 남습니다.
- **소방서**: 불이 나면 팔팔소방서 소방차가 출동해 물을 뿌리고, 화재가 훨씬 빨리 꺼집니다.
- **랜덤 이벤트**: 소나기, 광장 길고양이, 플리마켓, 버스킹, 치킨 파티, 몸살로 병원행, 훈련 중 부상, 우연한 만남.
- **성장**: 체력·지능·요리·업무·사교·매력 스킬(Lv.10까지)과 캐릭터별 기록(지각, 납치, 맥주, 야근 …).

## 파일

- `game/` — 게임 (`js/data.js` 주민·일과·팔팔법, `js/sim.js` 시뮬레이션, `js/law.js` 비밀번호·범죄·경찰, `js/memory.js` 대화 기억, `js/ai.js`·`js/ai-config.js` NPC AI, `js/director.js` AI 감독·일과·대형 사건, `js/traffic.js` 신호등·교통사고·구급차·경찰차·소방차, `js/world.js` 지도·건물 그래픽, `js/render.js`, `js/ui.js`)
- `server/` — (선택) API 키를 서버에 두는 Cloudflare Worker 프록시
- `characters/` — 스프라이트·초상화·페르소나 (`tools/generate_characters.py`로 재생성)
